## Topic: Operator Precedence
● It determines the order in which operators are evaluated in an expression when there are multiple operators.
● Operators with higher precedence are evaluated before those with lower precedence.
● Associativity defines the direction (left-to-right or right-to-left) in which operators of the same precedence are evaluated.

<!-- page: 93 -->

System.out.println("Result 1 (a + b * c): " + result1);
System.out.println("Result 2 ((a + b) * c): " + result2);
System.out.println("Result 3 (a + b - c): " + result3);
System.out.println("Result 4 (a + b * c - 1): " + result4);
}
}
