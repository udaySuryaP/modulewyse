# 17 — Release Criteria

## Private beta can start when
- signup/login/forgot password/signout work
- onboarding guard works
- profile/settings work
- student UI edge states work
- RLS is tested
- hidden content is not visible
- OOP content is ingested
- OOP retrieval works
- o4-mini generation works
- verifier works
- feedback works
- OOP eval pass rate is acceptable

## Do not release if
- retrieval mixes subjects/modules
- hidden chunks are readable
- model frequently hallucinates unsupported answers
- signout/session handling is broken
- OOP eval is incomplete
- common questions produce weak answers
