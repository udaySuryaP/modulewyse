# 03 — Student Design System

## Visual style
Warm cinematic glassmorphism inspired by premium AI product interfaces.

## Feel
Premium, futuristic, minimal, warm, calm, academic, spacious, AI-native, not childish edtech.

## Palette
- Burnt orange: `#B8653F`
- Clay brown: `#8F4B35`
- Deep rust: `#6F3328`
- Warm beige: `#D7A077`
- Dark charcoal: `#101111`
- Soft white: `#F8F5EF`
- Muted white: `rgba(255,255,255,0.72)`
- Glass surface: `rgba(255,255,255,0.10-0.16)`
- Glass border: `rgba(255,255,255,0.16-0.24)`

## Background
Full-screen warm gradient with subtle vignette, dark bottom/corners, blurred shapes, and optional grain.

## Glass cards
- backdrop blur 20–40px
- radius 18–28px
- thin translucent borders
- no heavy shadows
- stronger/darker glass for long text readability

## Typography
Main: Inter / Geist / DM Sans.  
Mono: IBM Plex Mono / DM Mono / JetBrains Mono.

Use uppercase mono for nav, badges, labels, metadata, buttons.

## Buttons
Primary: white background, black text, uppercase mono.  
Secondary: transparent glass, white border, white text.
