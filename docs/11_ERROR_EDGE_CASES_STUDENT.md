# 11 — Student Error and Edge Cases

## Auth
Invalid credentials, duplicate email, weak password, password mismatch, network error, session expired.

## Onboarding
Missing fields, disabled branch selected, setup saving, setup failed, already-onboarded redirect.

## Chat
No subject selected, subject coming soon, no content for module, answer loading, answer failed, insufficient source, rate limit, copy success, feedback success, long answer overflow.

## Subjects
No subjects, search no results, coming soon subject, beta warning, module unavailable.

## Library
No previous questions, filters no results, unsupported subject.

## Profile/settings
Save success, save failed, preferences saved, signout confirmation, signout failed, signed-out redirect.
