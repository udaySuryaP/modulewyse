# 00 — Master Plan

## Product summary
ModuleWyse is a student-facing AI exam-prep app for KTU CSE students. It gives clear, structured, exam-ready answers from curated academic material.

## Current strategic direction
```txt
CSE first
Important subjects first
OOP first
Student-side MVP first
Admin UI later
Content curated by developer/admin
o4-mini for generation and verification
text-embedding-3-small for embeddings
Supabase pgvector vector(1536)
```

## Why this scope
CSE subject module counts vary by scheme. KTU 2024 scheme subjects use Modules 1-4 only, so Module 5 must not be assumed for any KTU 2024 subject. Building all subjects before launch is the wrong move. The right move is to prove answer quality on important subjects first.

## First subject rollout
1. Object Oriented Programming
2. Database Management Systems
3. Operating Systems
4. Computer Networks
5. Data Structures

## Product promise
“Ask from selected KTU CSE subjects and get syllabus-grounded, module-aware, exam-ready answers from curated notes.”

## Do not claim
- Official KTU product
- Guaranteed pass
- Examiner-approved
- 100% perfect answers
- All KTU subjects
- All branches available

## Success definition
The MVP succeeds if students prefer ModuleWyse answers over generic chatbot answers for selected CSE subjects.
